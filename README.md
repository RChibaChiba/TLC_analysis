# TLC Densitometry

ブラウザだけで動作するTLC画像の簡易デンシトメトリーアプリです。サーバーや追加ライブラリは不要です。

## 起動

`index.html` をモダンブラウザで開いてください。`index.html`、`style.css`、`app.js`は同じフォルダに置きます。

## 使い方

1. JPGまたはPNGのTLC画像を選択します。
2. 必要に応じて反転を切り替え、暗い／明るいスポットを強度として扱います。
3. レーン位置をクリックして縦長の短冊を置きます。
4. 短冊一覧のチェックで解析対象を選択します。
5. 関数とピーク検出条件を設定してフィットします。
6. 表を確認し、必要に応じてCSVをダウンロードします。

## ファイル

- `index.html`: 画面構造
- `style.css`: デザイン
- `app.js`: 画像処理、ピークフィット、CSV出力

## 注意

Rfは画像上端を0、下端を1とした暫定値です。定量用途では原点・溶媒先端の校正、背景補正、標準試料による検証を行ってください。
